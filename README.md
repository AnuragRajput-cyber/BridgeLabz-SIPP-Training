# 🚀 OOPs Pseudocode Problems  

This repository contains solutions to Object-Oriented Programming (OOPs) problems written in **Java-style pseudocode**.  
The goal of this repo is to **practice OOP concepts** like inheritance, encapsulation, polymorphism, and composition without focusing on exact Java syntax.  

---

## 📌 Problems Covered  

### 1️⃣ Online Exam Portal (Role-Based Login System)  
- **Concepts Used:** Inheritance, Method Overriding, Polymorphism  
- **Description:**  
  - Base class `User` with common attributes and a `login()` method.  
  - `Student` subclass overrides login to check registration & enrollment.  
  - `Admin` subclass overrides login to check credentials & admin privileges.  
- **Real-World Relevance:** Models role-based login systems used in LMS platforms like Coursera or edX.  

---

### 2️⃣ Movie Ticket Booking System  
- **Concepts Used:** Encapsulation, Object Interaction, Composition  
- **Description:**  
  - `Ticket` class stores movie details, seat number, and status.  
  - `Theatre` manages schedules, available seats, and tickets.  
  - `Customer` browses, books, and cancels tickets.  
- **Real-World Relevance:** Similar to backend logic in BookMyShow, PVR, or AMC ticketing systems.
